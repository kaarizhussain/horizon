## The core call

For weeks the roadmap has been feature-forward — habits, estimates,
deep-work protection, digests, always-on — and all of it shipped. The good
news the reconcile surfaced: the loop it exists to serve (**goals → plan →
execute → learn**) is *already running on your real job search*. So the
highest-leverage move still isn't another feature — it's to **ship the
redesign (you touch that daily surface every morning) and instrument the
loop that's already live, letting a week of real use drive what's next.**
That's the honest way to hit your own bar ("remove real manual work"): you're
already the user, so watch where the friction actually is.

## Risks

  product; the discipline is to use the thing instead.
- **Doc/reality drift** — already happened once; M0 step 1 is the guard.
- **Single-tenant vs. portfolio ambiguity** — keeps making "is X worth it?"
  calls fuzzy. Name it: personal tool that *could* become a portfolio piece —
  so stay multi-tenant-safe, but don't build platform features yet.
- **Unsupervised automation cost** — M3's always-on planning is recurring
  Claude API spend running without you watching; arm it deliberately, not by
  default.
